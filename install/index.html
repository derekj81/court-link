Install Court Link on an M5Paper

The one-time USB install. After this, updates come over Bluetooth from the Court Link page on your phone.

You need

  1. A computer with desktop Chrome or Edge: Windows, Mac, Linux or a Chromebook. (Not a phone, and not Safari or Firefox.)
  2. A USB cable that carries data, from the computer to the M5Paper. For the original M5Paper, a USB-A to USB-C cable works most reliably.
  3. On Windows, if the M5Paper doesn't show up in the list below, install the USB driver for its serial chip: CH9102 / CH343 (WCH) for newer units, or CP210x (Silicon Labs) for older ones.

Install

  1. Plug in the M5Paper and press its side button so it's on.
  2. Press Install, then pick the M5Paper's port from the list (often named "USB Serial", "CP2104" or "CH9102").
  3. When asked, tick Erase device. That wipes everything that was on it before installing.
  4. Wait about a minute. When it says the install is done, the M5Paper restarts into Court Link.
This browser can't install firmware. Use desktop Chrome or Edge. This page needs a secure (https) address.

If no port appears: try another cable (many only charge), plug straight into the computer, and on a Mac check System Settings, Privacy & Security, "Allow accessories to connect".

Afterwards

  1. On your Android phone: Settings, Connected devices, Pair new device, pick CourtLink (for the record button).
  2. Open Court Link from Court Replay's Coach tab and press Connect, then Send pack.
