# Court Link

A phone page that links Court Replay to an M5Paper over Bluetooth: it sends a court pack
(warm-up, mantras, targets for each opponent) to the device and collects the games it logged.

Open it from Court Replay's Coach tab. The pack travels in the link's `#fragment`, which the
browser never sends to this server; everything stays on the phone. Needs Chrome on Android.

Add `?demo` to the address to try it with a pretend device.
